# CleanHabit

A household chore manager for families and flatmates. Assign tasks to rooms and people, track who did what, approve completed work, and keep everyone motivated with goals, badges and a leaderboard.

CleanHabit is a native Android app (Flutter) backed by a small Flask + SQLite API. Both live in this repository.

## Features

- Tasks and rooms with recurrence, assignees and one-time tasks
- Optional parent/admin approval of completed tasks
- Family view with ranking and roles (owner, admin, member)
- Calendar of what is due today and later
- Goals, goal templates and a badge system
- Voice assistant (speech-to-text / text-to-speech; answers are generated by Claude when `ANTHROPIC_API_KEY` is configured)
- MCP server so AI assistants can read and manage household tasks
- Google Play subscriptions with server-side purchase verification
- Localized in English, Polish and Ukrainian
- Light and dark themes

## Repository layout

```
app.py              Flask backend (REST API, SQLite)
templates/          Web UI (single-page app), landing page, kiosk view
static/             PWA manifest and service worker
mcp_server.py       MCP server
flutter_app/        Native Android client (Flutter, provider + dio)
Dockerfile          Container image for the backend
docker-compose.yml  Example deployment
```

## Running the backend

```bash
pip install -r requirements.txt
cp .env.example .env   # then fill in the values (see table below)
python app.py          # http://localhost:5000
```

Configuration is read from environment variables:

| Variable | Purpose |
| --- | --- |
| `SECRET_KEY` | Flask session secret (random per process if unset) |
| `ANTHROPIC_API_KEY` | Enables the Claude-powered voice assistant |
| `RTDN_WEBHOOK_SECRET` | Shared secret for Google Play real-time notifications |
| `RFID_SCAN_SECRET` | Secret for the optional RFID device endpoint |

Google Play verification also needs a service account JSON file (`google-service-account.json`), which is intentionally not part of the repository.

Or with Docker:

```bash
docker compose up -d
```

## Building the Android app

```bash
cd flutter_app
flutter pub get
flutter run                # debug on a device or emulator
flutter build apk          # release builds need your own keystore (android/key.properties)
```

Release signing keys and service account files are git-ignored. Supply your own.
